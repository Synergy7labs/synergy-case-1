# Synergy Case 1 – Debugging & Reasoning

## Bakgrund
Du får ett litet API med en bugg. Tanken är att efterlikna ett verkligt scenario där något inte fungerar som det ska.

## Uppgift

Du får ett enkelt kodcase.

Börja med Steg 1.  
Om du vill kan du fortsätta vidare.

### Steg 1 (ca 15–20 min)

- Läs koden
- Vad är fel?
- Skriv kort vad du tror är problemet

### Steg 2 (ca 15–20 min)

- Fixa buggen i koden

### Steg 3 (valfri)

- Finns något du hade förbättrat?
- Kort förklaring räcker

### Mål

Det viktiga är inte perfekt kod, utan hur du tänker.


(Funktionen returnerar fel resultat - hitta vad som är fel och varför)


## Leverans

Du väljer själv hur långt du vill gå:

- Steg 1: vad tror du är fel?
- Steg 2: fixa buggen i koden
- Steg 3 (valfri): vad hade du förbättrat?
Du kan svara kort - fokus är hur du tänkte, inte perfekt kod.

## Viktigt
Det viktigaste är inte att allt blir perfekt, utan att visa:
- hur du angriper problemet
- hur du resonerar
- hur du förklarar din lösning
